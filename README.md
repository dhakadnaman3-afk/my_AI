# 🤖 My AI Chatbot

An AI-powered chatbot built with Python that can interact with users and maintain conversation history.

## 🚀 Features

- 💬 AI-powered chat interface
- 🧠 Conversation history
- 💾 SQLite database for storing chat history
- 🔐 Environment variables for API keys
- 🐍 Built with Python
- 🌐 Simple web interface
- 📁 Clean project structure

## 🛠️ Tech Stack

- Python
- HTML
- CSS
- SQLite
- AI / LLM API
- python-dotenv
